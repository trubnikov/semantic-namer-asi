# SemanticNamer ASI
Figma plugin that renames layers semantically using an LLM (Groq / Anthropic APIs). TypeScript, plugin API 1.0.

**Status:** 🟡 paused (2026-04)

## Quick start
```bash
npm install
npx tsc -w            # compiles code.ts → code.js
```
Figma → Plugins → Development → Import plugin from manifest → `manifest.json`. Enter an API key in the plugin UI.
